# SAMSUC Blog — how to add an article

1. Copy any folder under `blog/` (for example `blog/how-to-set-up-church-livestream/`).
2. Rename the folder to a short slug: `my-new-article`.
3. Edit `index.html`:
   - `<title>` and meta description
   - canonical URL: `https://samsuc.github.io/resource-hub/blog/my-new-article/`
   - H1, body copy, internal links
4. Add a card on `blog/index.html` linking to `my-new-article/`.
5. Add the URL to `sitemap.xml`.
6. Optionally append an entry to `articles.json` (registry for humans/tools).

Keep claims factual. Link to real product pages only.
