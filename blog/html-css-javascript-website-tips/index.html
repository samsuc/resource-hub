Website templates

HTML, CSS, and JavaScript website tips

Small structural habits make templates easier to customize and less fragile when you change content later.

HTML: meaning over div soup

Use headings in order.

Label buttons and links with text that still makes sense out of context.

Keep one H1 per page.

CSS: limit the system

Reuse spacing and type sizes.

Prefer a small set of components over one-off styles for every section.

JavaScript: progressive enhancement

Core content should remain available if a script fails.

Avoid shipping interaction you cannot maintain.
